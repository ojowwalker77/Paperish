Paperish is a design canvas where human and agent operators can bounce off each other ideas and explorations. 
Paperish itself should mantain a calm interface focused on software engineers.

Some repo rules:
1. Avoid noise: dont comment code, dont introduce regression tests for unreleased things or fixes we made along the way.
2. Keep PRs simple for human to quick read. 
3. Run scripts/checks everytime before commiting.
4. When starting from a worktree after opening your PR checkout to local and remove your worktree and artifacts so you keep the developer machine clean.
5. Babysit your PR for code reviews and CI
